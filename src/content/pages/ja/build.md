## 部品

5つの品で、そのうち3つはすでにお持ちかもしれません。

| 部品 | 選ぶポイント | 目安 |
|---|---|---|
| Raspberry Pi | **3B、3B+、または4**が理想的です。メモリ1 GBで受信機、フィーダー、ウォールのすべてに足ります。これは作者のPi 3Bで実測した値です。**Zero 2 W**（512 MB、定価15 US$）は受信機とウォールを動かせますが、追加のフィーダーは載せられません。 | 15〜60 € |
| USB無線スティック | **RTL-SDR**ドングルです。RTL-SDR Blogのモデルが定番で、35〜40 US$程度です。1090 MHzのフィルターを内蔵したADS-B専用のスティック（たとえばFlightAwareのPro Stick）は、都市部でより遠くまで聞こえます。 | 30〜45 € |
| アンテナ | **1090 MHz**に合わせた小型アンテナです。一部のスティックに付属するものは窓際で使えます。長さ半メートルほどのADS-B専用アンテナなら、屋根やバルコニーでずっと遠くまで聞こえます。 | 10〜40 € |
| Micro-SDカード | 16 GB以上の、信頼できるブランドのもの。 | 8〜12 € |
| 電源 | お使いのPi用の公式のもの。スマートフォンの充電器では足りないことが多く、その場合Piは稲妻のアイコンで知らせてきます。 | 8〜12 € |

合計：**およそ60〜120 €**、一度きりです。価格は変動します。これは2026年10月にメーカーのサイトで見られたおおよその水準です。アンテナは最後に買ってください。まずはスティックに付属のもので始め、何が聞こえるかを確かめてから決めましょう。

ウォール用の古いタブレットやブラウザ付きの画面は任意で、おそらく引き出しの中にすでにあるでしょう。

## アンテナをどこに置くか

受信範囲を変える唯一の要素なので、少し時間をかける価値があります。信号は直進します。アンテナが欲しいのは部屋ではなく空です。窓際が最低限、バルコニーなら良好、屋根や瓦の下の屋根裏が最良です。垂直に、金属から離して、ケーブルが許す限り高く。2メートル高くするほうが、高価なスティックに勝ることがよくあります。

Pi本体は屋内に置いたままで構いません。USBケーブルは3メートル程度までなら問題ありません。夏にスティックが熱くなるのは正常です。

## ソフトウェア、2つの方法

### 定番の方法：readsbとtar1090

デコーダーは[**readsb**](https://github.com/wiedehopf/readsb)、ブラウザ上の地図は[**tar1090**](https://github.com/wiedehopf/tar1090)です。どちらも同じ作者による自由ソフトウェアで、まっさらなRaspberry Pi OSで動くインストールスクリプトが用意されています。その後、各ネットワークのページから各フィーダーを手動で追加します。一つひとつの部品を理解したい方には、こちらの方法が向いています。

### オールインワンの方法：ZenithBoard

ZenithBoardは、readsb、選んだフィーダー、ウォールを1つのメニューからインストールし、いくつかの質問（地域、単位、アンテナの位置）を一度だけ尋ね、後からどの部分でも追加・削除できるようにします。また、MLATクライアントを1つだけ動かし続けます。複数同時に動かすとPiに負荷がかかりすぎるからです。

Raspberry Pi Imagerでカードを準備し（Raspberry Pi OS Lite、64ビット、SSHを有効にしてWi-Fi情報を入力）、Piを起動して、お使いのコンピューターから次を実行します。

```
ssh YOUR_USERNAME@zenithboard.local
sudo apt update && sudo apt install -y git
git clone https://github.com/regis57/ZenithBoard.git
cd ZenithBoard
sudo ./install.sh
```

初回はおよそ1時間かかりますが、ほとんどはダウンロードの待ち時間です。完了すると、メニューがウォールのアドレス `http://<Piのアドレス>:8080/` を表示します。タブレットのブラウザで開けば、ウォールが現れます。あなた自身の地図であるtar1090は `http://<Piのアドレス>/tar1090/` にあります。

## あなたの位置

デコーダー、MLAT、ウォールの距離表示は、アンテナがどこにあるかを知る必要があります。緯度、経度、高度です。地図上で自宅を右クリックして座標をコピーしてください。この位置はPiとフィーダーの設定の中にとどまります。ZenithBoardはこれをウォールにも投稿にも決して表示せず、ネットワークも公開しません。受信範囲をそこから測る、それだけです。

## うまくいかないとき

スティックが見つからない：Pi 4の青いUSB 3.0ポートではなくUSB 2.0ポートを使い、短いケーブルを使ってください。地図が空のまま：10分待ってから、アンテナが垂直で窓の近くにあるか確認してください。Piに稲妻のアイコンが出る：電源が弱すぎます。Wi-Fiが切れる：ケーブルを使うか、Piを移動してください。受信機自体に必要な帯域はごくわずかです。残りはFAQにあります。
