## 零件

五樣東西，其中三樣你可能已經有了。

| 零件 | 該注意什麼 | 大約 |
|---|---|---|
| Raspberry Pi | **3B、3B+ 或 4** 最理想：1 GB 記憶體就足以跑接收器、餵送程式和那面牆，這是在作者的 Pi 3B 上實測的。**Zero 2 W**（512 MB，定價 15 US$）可以跑接收器和那面牆，但不含額外的餵送程式。 | 15–60 € |
| USB 無線電接收棒 | 一支 **RTL-SDR** 接收棒。RTL-SDR Blog 的型號是參考標準，大約 35–40 US$。專為 ADS-B 設計、內建 1090 MHz 濾波器的接收棒（例如 FlightAware 的 Pro Stick），在城市裡聽得更遠。 | 30–45 € |
| 天線 | 一支調到 **1090 MHz** 的小天線。有些接收棒附的那支放在窗邊就能用；專用的 ADS-B 天線，約半公尺長，放在屋頂或陽台上能聽得遠得多。 | 10–40 € |
| Micro-SD 卡 | 16 GB 以上，知名品牌。 | 8–12 € |
| 電源供應器 | 你那款 Pi 的官方電源。手機充電器常常不夠力，Pi 會用一個閃電圖示告訴你。 | 8–12 € |

總計：**大約 60 到 120 €**，一次性。價格會變動；這些是 2026 年 10 月在製造商網站上看到的量級。天線最後再買：先用接收棒附的那支，看看你能聽到什麼，再做決定。

用來當牆的舊平板或任何有瀏覽器的螢幕是選配，而且八成已經躺在某個抽屜裡。

## 天線該放哪裡

這是唯一會改變你接收距離的東西，所以值得花一分鐘。訊號是直線傳播的。天線要的是天空，不是房間：窗戶是最低限度，陽台不錯，屋頂或瓦片下的閣樓最好。垂直放置、遠離金屬、線能拉多高就放多高。高兩公尺往往勝過一支更貴的接收棒。

Pi 本身可以留在室內；USB 線在大約三公尺以內都沒問題。接收棒在夏天會發熱，這是正常的。

## 軟體，兩種方式

### 經典方式：readsb 和 tar1090

解碼器是 [**readsb**](https://github.com/wiedehopf/readsb)；瀏覽器裡的地圖是 [**tar1090**](https://github.com/wiedehopf/tar1090)；兩者都是同一位作者的自由軟體，附有可在全新 Raspberry Pi OS 上運作的安裝腳本。接著你從各個網路自己的頁面，手動加入每一個餵送程式。如果你喜歡理解每一個環節，這是該走的路。

### 一次到位的方式：ZenithBoard

ZenithBoard 從一個選單安裝 readsb、你選擇的餵送程式和那面牆，只問你一次那幾個問題（你的地區、你的單位、你的天線在哪裡），之後隨時可以新增或移除任何部分。它也只讓一個 MLAT 用戶端保持運行，因為同時跑好幾個會讓 Pi 不堪負荷。

用 Raspberry Pi Imager 準備記憶卡（Raspberry Pi OS Lite，64 位元，啟用 SSH 並填入你的 Wi-Fi），啟動 Pi，然後在你的電腦上：

```
ssh YOUR_USERNAME@zenithboard.local
sudo apt update && sudo apt install -y git
git clone https://github.com/regis57/ZenithBoard.git
cd ZenithBoard
sudo ./install.sh
```

第一次大約要一小時，大部分時間都在等下載。完成後，選單會印出牆的位址 `http://<the Pi's address>:8080/`；在平板的瀏覽器裡打開它，牆就在那裡了。你自己的地圖 tar1090 在 `http://<the Pi's address>/tar1090/`。

## 你的位置

解碼器、MLAT 和牆上的距離都需要知道天線在哪裡：緯度、經度、海拔。在地圖上對你家按右鍵就能複製座標。這個位置只留在你的 Pi 上和餵送程式的設定裡；ZenithBoard 絕不會在牆上或貼文裡顯示它，各網路也不會公開它。它只用來計算距離，僅此而已。

## 可能出什麼問題

找不到接收棒：用 USB 2.0 連接埠，不要用 Pi 4 上藍色的 USB 3.0，並用短一點的線。地圖是空的：給它十分鐘，然後檢查天線是否垂直且靠近窗戶。Pi 顯示閃電圖示：電源供應器太弱。Wi-Fi 斷線：接網路線，或把 Pi 搬個位置；接收器本身需要的頻寬非常少。其餘的請看常見問題。
