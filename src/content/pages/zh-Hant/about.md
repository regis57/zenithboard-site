## 是誰

ZenithBoard 和這個網站由 Régis Hennequin 製作，他住在法國東部的摩澤爾（Moselle），從第一個版本起，參考用的 Raspberry Pi 就一直在那裡的戶外運行。程式碼以 [regis57](https://github.com/regis57) 的名義公開在 GitHub 上，每一個版本發佈前都會在那台 Pi 上測試。這個專案背後的故事寫在[他自己的網站上](https://regis-hennequin.info/beyond-the-desk/adsb/zenithboard/)。

## 承諾

你頭頂的天空，由你解碼，與全世界分享。這裡的一切都為這句話服務：接收器是你的，資料是公開的，而地圖之所以存在，是因為人們分享。沒有任何東西要賣，也不收集任何東西。

## 授權

ZenithBoard 的程式碼採用 **GNU General Public License，第 3 版或更新版本**：你可以使用、閱讀、修改並轉散布它，條件是沿用相同的條款。本網站的文字採用 **Creative Commons Attribution – ShareAlike 4.0**：引用它、翻譯它、重新使用它，只要註明出處並沿用相同授權。本網站自身的程式碼也採用 GPL，放在它自己的公開程式庫中，讓任何人都能檢查它做了什麼。

## 對人的尊重

牆和貼文絕不洩露接收器的位置。不繪製任何航空公司標誌或製造商標誌，無論是點陣還是其他形式：這些是受保護的商標，點陣版的複製品仍然是複製品，所以用國旗代替。飛機照片依攝影師發佈的原樣呈現，附上他們的名字和連結，絕不複製或轉貼到別處。本網站不設定任何 cookie，不執行任何分析工具，不從任何第三方載入任何東西；你在頁面底部選的顏色，只保存在你自己的瀏覽器裡。

## 二十種語言

ZenithBoard 的網頁和本網站有二十種語言，因為天空在哪裡都一樣，雅加達或里加的接收器和里昂的接收器一樣受歡迎。英文和法文由作者撰寫；其他語言經過細心翻譯，正由母語人士審閱中。如果你在自己的語言裡發現某句話讀起來不對勁，程式庫樂於接受修正：每一頁都是一個純文字檔。

## 說聲謝謝

ZenithBoard 是免費的，也會一直免費。如果它給了你一個抬頭看天的夜晚，一杯啤酒就是謝意：它不解鎖任何東西，不給任何優勢，只是幫忙分攤伺服器和 Pi 的電費。按鈕在每一頁的底部，一個簡單的連結，背後沒有任何腳本。

## 寫信給作者

錯誤回報、想法和翻譯請送到 GitHub 上的 [ZenithBoard 程式庫](https://github.com/regis57/ZenithBoard)，以 issue 或 pull request 的形式。[本網站的程式庫](https://github.com/regis57/zenithboard-site)是獨立的；它的 README 說明了頁面如何編輯和發佈。
