## 谁

ZenithBoard 和本站由 Régis Hennequin 制作，他在法国东部的摩泽尔，参考用的 Raspberry Pi 从第一个版本起就一直在那里的户外运行。代码以 [regis57](https://github.com/regis57) 的名义公开在 GitHub 上，每个版本发布前都会在那块 Pi 上测试。项目背后的故事写在[他自己的网站](https://regis-hennequin.info/beyond-the-desk/adsb/zenithboard/)上。

## 承诺

你头顶的天空，由你自己解码，与全世界分享。这里的一切都为这句话服务：接收器是你的，数据是公开的，地图之所以存在是因为人们在分享。没有任何东西出售，也不收集任何东西。

## 许可证

ZenithBoard 的代码采用 **GNU General Public License，第 3 版或更高版本**：你可以使用、阅读、修改并传播它，但须遵守同样的条款。本站的文字采用 **Creative Commons Attribution – ShareAlike 4.0**：引用、翻译、再利用都可以，只需注明出处并采用同样的许可证。本站自身的代码同样采用 GPL，放在它自己的公开仓库里，任何人都可以检查它在做什么。

## 对人的尊重

"墙"和帖子绝不会泄露接收器的位置。不绘制任何航空公司标志或制造商标志，无论是点阵还是其他形式：这些是受保护的商标，点阵复制品依然是复制品，所以用国旗代替。飞机照片按摄影师发布时的样子展示，附其姓名和链接，绝不复制或转发到别处。本站不设置 cookie，不做任何分析统计，不从第三方加载任何东西；你在页面底部选择的颜色只保存在你自己的浏览器里。

## 二十一种语言

ZenithBoard 的网页和本站有二十一种语言版本，因为天空在哪里都一样，雅加达或里加的接收器和里昂的接收器同样受欢迎。英文和法文由作者撰写；其他语言经过用心翻译，正在由母语者审校。如果你发现某句话在你的语言里读起来不对，代码仓库乐意接受修正：每个页面都是一个纯文本文件。

## 说声谢谢

ZenithBoard 是免费的，并将一直免费。如果它让你度过了一个仰望天空的夜晚，一杯啤酒就是一声谢谢：它不解锁任何东西，不带来任何特权，只是帮忙支付服务器和 Pi 的电费。按钮在每个页面的底部，一个简单的链接，背后没有任何脚本。

## 给作者写信

Bug、想法和翻译请提交到 GitHub 上的 [ZenithBoard 仓库](https://github.com/regis57/ZenithBoard)，以 issue 或 pull request 的形式。[本站的仓库](https://github.com/regis57/zenithboard-site)是独立的；它的 README 解释了页面如何编辑和发布。
