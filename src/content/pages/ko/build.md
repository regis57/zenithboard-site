## 부품

다섯 가지인데, 그중 셋은 이미 갖고 계실지도 몰라요.

| 부품 | 무엇을 볼 것인가 | 가격대 |
|---|---|---|
| Raspberry Pi | **3B, 3B+ 또는 4**가 이상적이에요. 메모리 1 GB면 수신기, 피더, 월까지 충분하며, 제작자의 Pi 3B에서 측정한 결과예요. **Zero 2 W**(512 MB, 정가 15 US$)는 추가 피더 없이 수신기와 월을 돌립니다. | 15–60 € |
| USB 라디오 스틱 | **RTL-SDR** 동글이에요. RTL-SDR Blog 모델이 기준이고, 35–40 US$ 정도예요. 1090 MHz 필터가 내장된 ADS-B 전용 스틱(예를 들어 FlightAware의 Pro Stick)은 도시에서 더 멀리 들어요. | 30–45 € |
| 안테나 | **1090 MHz**에 맞춘 작은 안테나예요. 일부 스틱에 딸려 오는 것도 창가에서는 쓸 만하고, 반 미터 길이의 ADS-B 전용 안테나는 지붕이나 발코니에서 훨씬 멀리 들어요. | 10–40 € |
| Micro-SD 카드 | 16 GB 이상, 알려진 브랜드로요. | 8–12 € |
| 전원 어댑터 | 여러분의 Pi용 정품이에요. 휴대폰 충전기는 부족한 경우가 많고, 그러면 Pi가 번개 아이콘으로 알려 줍니다. | 8–12 € |

합계: **약 60~120 €**, 한 번만이에요. 가격은 변해요. 이 숫자는 2026년 10월에 제조사 사이트에서 본 대략의 규모예요. 안테나는 맨 나중에 사세요. 스틱에 딸려 온 것으로 시작해서, 무엇이 들리는지 보고, 그다음에 결정하세요.

월을 위한 오래된 태블릿이나 브라우저가 있는 아무 화면은 선택 사항이고, 아마 이미 서랍 속에 있을 거예요.

## 안테나를 어디에 둘까

거리를 바꾸는 건 이것뿐이니, 1분쯤 들일 가치가 있어요. 신호는 직선으로 가요. 안테나가 원하는 건 방이 아니라 하늘이에요. 창문이 최소, 발코니가 좋고, 지붕이나 기와 아래 다락이 최고예요. 수직으로, 금속에서 떨어뜨려, 케이블이 허락하는 한 높이요. 2 m 더 높이 두는 것이 더 비싼 스틱보다 나을 때가 많아요.

Pi 자체는 실내에 두어도 돼요. USB 케이블은 약 3 m까지 괜찮아요. 여름에 스틱이 뜨거워지는 건 정상이에요.

## 소프트웨어, 두 가지 방법

### 고전적인 방법: readsb와 tar1090

디코더는 [**readsb**](https://github.com/wiedehopf/readsb), 브라우저의 지도는 [**tar1090**](https://github.com/wiedehopf/tar1090)이에요. 둘 다 같은 제작자의 자유 소프트웨어이고, 새로 설치한 Raspberry Pi OS에서 동작하는 설치 스크립트가 있어요. 그다음 각 네트워크의 페이지에서 피더를 하나씩 손으로 추가해요. 모든 조각을 이해하고 싶은 분이라면 이 길이에요.

### 올인원 방법: ZenithBoard

ZenithBoard는 readsb, 여러분이 고른 피더, 그리고 월을 메뉴 하나에서 설치하고, 몇 가지 질문(지역, 단위, 안테나 위치)을 한 번만 물은 뒤, 나중에 어떤 부분이든 추가하거나 제거할 수 있게 해 줘요. 또 MLAT 클라이언트를 하나만 돌리도록 유지해요. 여러 개를 동시에 돌리면 Pi에 과부하가 걸리거든요.

Raspberry Pi Imager로 카드를 준비하고(Raspberry Pi OS Lite, 64비트, SSH 활성화, Wi-Fi 정보 입력), Pi를 켠 다음, 컴퓨터에서:

```
ssh YOUR_USERNAME@zenithboard.local
sudo apt update && sudo apt install -y git
git clone https://github.com/regis57/ZenithBoard.git
cd ZenithBoard
sudo ./install.sh
```

처음에는 한 시간쯤 잡으세요. 대부분은 다운로드를 기다리는 시간이에요. 끝나면 메뉴가 월의 주소 `http://<the Pi's address>:8080/`를 출력해요. 태블릿의 브라우저에서 열면 월이 거기 있어요. 여러분만의 지도인 tar1090은 `http://<the Pi's address>/tar1090/`에 있어요.

## 여러분의 위치

디코더, MLAT, 그리고 월의 거리 표시는 안테나가 어디에 있는지 알아야 해요. 위도, 경도, 고도요. 지도에서 집을 오른쪽 클릭하면 좌표를 복사할 수 있어요. 이 위치는 여러분의 Pi와 피더 설정에만 남아요. ZenithBoard는 월에도 게시물에도 절대 보여 주지 않고, 네트워크들도 공개하지 않아요. 거리를 재는 기준점일 뿐이에요.

## 잘못될 수 있는 것

스틱을 찾지 못해요: Pi 4의 파란 USB 3.0 포트 말고 USB 2.0 포트에, 짧은 케이블로 꽂으세요. 지도가 비어 있어요: 10분을 주고, 그다음 안테나가 수직이고 창가에 있는지 확인하세요. Pi에 번개 아이콘이 떠요: 전원 어댑터가 너무 약해요. Wi-Fi가 끊겨요: 케이블을 쓰거나 Pi를 옮기세요. 수신기 자체는 대역폭이 아주 조금만 필요해요. 나머지는 FAQ에 있어요.
