# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's private vulnerability reporting: go to the Security tab of this repository and choose "Report a vulnerability".

You should get a first reply within a few days. Once the issue is confirmed, a fix will be published as soon as possible and you will be credited if you wish.

## Scope

This repository holds the source of a static website. Reports about its code, its dependencies and its build and deployment workflows are welcome.
